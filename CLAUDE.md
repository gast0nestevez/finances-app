# Normas generales
- Evitar comentarios en el código y usar tipado extremadamente estricto.
- Los import deben llevar extensión (.ts, .tsx...).
- Los export se deben hacer al final, y se deben exportar los types por separado.
- Se prefieren las funciones arrow, en lugar de la forma de declarar funciones con `function`.

# Flujo de trabajo con Git
- Antes de empezar una feature, crear una rama nueva con un nombre corto y descriptivo. Los nombres de ramas y commits deben estar en inglés.
- Commitear en esa rama con mensajes claros, pero no pushear. El push lo hace el usuario manualmente. Se prefiere que el trabajo se separe en varios commits pequeños y declarativos dentro de una misma rama.
